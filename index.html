03精选论文

01PUBLISHED2026

Text-Image Guided Retrieval Network for Triple-Modal Images Few-Shot Semantic Segmentation

面向三模态图像的小样本语义分割文本-图像引导检索网络

提出 TIGRNet，将文本信息引入多模态小样本分割，通过文本引导的模态融合与分阶段目标检索，增强跨模态理解。在 VDT-2048-5i 数据集上，平均 mIoU 提升 8.8%，平均 FB-IoU 提升 3.8%。

IEEE Signal Processing Letters第一作者2025.07 — 2026.05
02MAJOR REVISION2026

QM-SAM: Quality-Guided and Modality-Adapted Segment Anything Model for Arbitrary Modality Salient Object Detection

质量引导与模态自适应的 Segment Anything 任意模态显著性目标检测模型

构建显著性感知质量评估与多模态自适应融合框架，以质量信号调节不同模态贡献，并将融合特征适配至 SAM。在 AM-XD 上，相较最优对比方法，平均 MAE 降低 44.9%，F-measure 提升 8.7%。
